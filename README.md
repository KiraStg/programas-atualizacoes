# Programas e atualizações

Instaladores para Windows.

Os instaladores com atualização automática precisam ser instalados uma vez. Depois, ao abrir o programa com conexão, ele avisa quando há uma versão nova. O uso normal continua disponível sem conexão.

Nesses programas, a atualização é opcional: quando aceita, é baixada e conferida, e a instalação ocorre depois que o programa fecha. Ela estará pronta na próxima abertura.

## Canal de atualização

Este repositório distribui os instaladores. Chaves privadas e dados pessoais de configuração não fazem parte da publicação.
